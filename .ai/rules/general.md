# General

## No Google services that need a Cloud console, API key or billing
Owner decision, 2026-08-20. The line is the billing relationship, not the Google
name: anything requiring a Google Cloud project, an API key or a billing account is
out — Safe Browsing, Maps, Cloud Vision, reCAPTCHA Enterprise. Free services that
need no account and no billing are fine, including Google Fonts.

If a task specifies one of the billed services (M1-T5 originally named Google Safe
Browsing), find and propose an alternative rather than opening a Cloud project.
