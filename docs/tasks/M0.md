## M0-T2 — Core schema migration — size M
**Scope:** one migration file creating:
- `qr_codes`: `id` ulid pk, `user_id` fk, `slug` varchar(8) unique, `type`
  enum(`url`,`whatsapp`,`file`,`vcard`,`linkpage`), `destination` json, `style` json
  nullable, `status` enum(`active`,`paused`,`grace`,`blocked`,`over_quota`) default
  `active`, `scan_count` unsigned int default 0, `last_scanned_at` nullable,
  timestamps, softDeletes. Index (`user_id`,`status`).
- `scan_events`: `id` bigint pk, `qr_code_id` fk, `occurred_at` datetime index,
  `ip_hash` char(64), `country` char(2) nullable, `region` varchar(64) nullable,
  `city` varchar(64) nullable, `device` enum(`mobile`,`desktop`,`tablet`,`other`),
  `os` varchar(32) nullable, `browser` varchar(32) nullable, `is_unique` bool,
  `is_bot` bool default false, `referer` varchar(255) nullable.
  Composite index (`qr_code_id`,`occurred_at`). **No** updated_at (append-only).
- `scan_daily_aggregates`: `qr_code_id`, `date`, `scans` int, `uniques` int,
  unique(`qr_code_id`,`date`).
- `scan_dim_aggregates`: `qr_code_id`, `date`, `dim` enum(`city`,`device`,`os`,`hour`),
  `key` varchar(64), `count` int, unique(`qr_code_id`,`date`,`dim`,`key`).
**Not building:** models beyond bare Eloquent classes + casts; no domains table.
**Acceptance:** `php artisan migrate:fresh` clean; inserting two aggregate rows with
the same (qr_code_id,date) throws; enum rejects unknown status.
**Review focus:** json casts on `destination`/`style`; append-only scan_events.

## M0-T3 — PlanConfig + entitlements service — size M
**Scope:** `config/plans.php` — single source of truth:
`free|regular|plus|business` → `max_codes` (3/10/100/500), `scan_cap_per_code`
(500/null/null/null), `retention_days` (7/365/365/null), `interstitial` (true/false…),
`vector_export`, `bulk`, `api_quota` (0/0/3000/10000), `analytics_depth`
(`basic`/`basic`/`advanced`/`advanced`), `seats` (1/1/2/5), monthly/annual price ints.
`Entitlements` service reading the user's active plan (boilerplate subscription) with
`can(string $feature): bool`, `limit(string $key): ?int`, cached per-request. Gate
`create-qr-code` denies when active (non-deleted) codes ≥ max_codes.
**Not building:** UI, checkout, middleware on routes that don't exist yet.
**Acceptance:** unit tests — free user with 3 codes denied a 4th; soft-deleted codes
don't count; unknown plan falls back to `free` and logs a warning (never throws in the
redirect path).
**Review focus:** fallback-to-free on missing subscription rows.
